# 🍔 Food Delivery App - Frontend

A modern, feature-rich food delivery application built with React. This application provides a seamless experience for customers to order food from their favorite restaurants, with real-time order tracking and multiple payment options.

## ✨ Features

### 👤 Customer Features
- User authentication (Login/Signup)
- Browse restaurants with filters and search
- View restaurant details and menu
- Add items to cart with customization
- Place orders with multiple payment methods
- Real-time order tracking
- Order history and reorder
- Rate and review restaurants
- Wishlist functionality
- Push notifications
- Dark/Light theme support

### 🏪 Restaurant Owner Features
- Restaurant profile management
- Menu management (CRUD operations)
- Order management with status updates
- Sales analytics and reports
- Customer reviews management
- Offer management

### 🚚 Delivery Partner Features
- View assigned deliveries
- Update delivery status
- Real-time location tracking
- Earnings dashboard
- Delivery history
- Rating system

### 👑 Admin Features
- Dashboard with analytics
- User management
- Restaurant management
- Order management
- Delivery partner management
- Report generation
- System settings

## 🛠️ Tech Stack

### Frontend
- **React 18** - UI library
- **React Router v6** - Routing
- **Context API** - State management
- **Axios** - HTTP requests
- **Socket.io-client** - Real-time updates
- **React Hook Form** - Form handling
- **React Hot Toast** - Notifications
- **Framer Motion** - Animations
- **Chart.js / Recharts** - Analytics charts
- **React Leaflet** - Maps integration
- **Stripe / Razorpay** - Payment gateways

### Styling
- **CSS Modules** - Component styling
- **CSS Variables** - Theming
- **Responsive Design** - Mobile-first approach

### Development Tools
- **ESLint** - Code linting
- **Prettier** - Code formatting
- **Husky** - Git hooks
